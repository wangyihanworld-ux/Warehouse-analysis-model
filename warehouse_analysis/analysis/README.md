# 仓库经营分析指标口径

本文件记录 `warehouse_analysis.analysis.summary` 输出的经营分析指标定义。
第四阶段只组合现有FIFO计算结果，不修改FIFO、费率匹配或仓储费计算口径。

## 期初库存量（吨）

- 业务含义：统计期间开始时可供后续出库消耗的FIFO库存余额。
- 数学公式：统计开始日当天流水发生前，各FIFO批次剩余数量之和。
- 数据来源：期初库存和统计开始日之前的全部出入库流水，通过现有
  `_rebuild_fifo` 重建。
- 注意事项：
  - 统计开始日当天的流水不进入期初余额。
  - 标准输入中的期初批次属于统计开始时点的初始条件，因此基准日期等于
    统计开始日的期初批次仍计入期初余额。
  - 不能直接对原始期初文件求和；开始日前发生的出入库必须经过FIFO回放。

## 期间入库量（吨）

- 业务含义：统计期间内实际发生的入库流量。
- 数学公式：`Σ 期间内方向=入库的数量`。
- 数据来源：标准化后的出入库明细。
- 注意事项：
  - 日期范围包含统计开始日和统计截止日。
  - 只统计当前期间，不能使用截止日之前的累计入库量。

## 期间出库量（吨）

- 业务含义：统计期间内实际发生的出库流量。
- 数学公式：`Σ 期间内方向=出库的数量`。
- 数据来源：标准化后的出入库明细。
- 注意事项：
  - 日期范围包含统计开始日和统计截止日。
  - 采用原始出库流水数量，不以FIFO成功分摊数量替代。
  - 只统计当前期间，不能使用累计出库量。

## 期末库存量（吨）

- 业务含义：统计截止日仍存放在仓库内的货物数量。
- 数学公式：`Σ 统计截止日仍在库批次余量`。
- 数据来源：现有 `EngineResult.warehouse_total` 的“当前总库存量（吨）”。
- 注意事项：不在分析层重新计算，与FIFO结果必须完全一致。

## 平均库存量（吨）

- 业务含义：用月末时点库存反映统计期间的平均库存占用水平。
- 数学公式：`Σ（月末库存量）÷ 月末数据点数`。
- 数据来源：现有月末FIFO快照及 `warehouse_total` 中的移动平均结果。
- 注意事项：
  - 保持当前系统口径：只统计统计期末仍有库存的物料。
  - 本阶段不改变这一范围。
  - 未来若需纳入期间内已经清零的物料，必须新增显式配置项并重新验证。

## 平均存放天数

- 业务含义：全部计费货物每吨平均占用仓库的天数。
- 数学公式：`Σ（数量×存放天数）÷Σ数量`。
- 数据来源：现有 `EngineResult.batch_details`。
- 统计范围：已出库明细和仍在库明细。
- 注意事项：
  - 使用重量加权平均，不使用批次简单平均。
  - 已有“已出库加权平均周转天数”和“仍在库加权平均库龄”继续保留在
    原汇总结果中，本指标不替代二者。

## 平均仓储费率（元/吨/天）

- 业务含义：全部计费明细折算后的综合日费率。
- 数学公式：`仓储费总额÷Σ（数量×存放天数）`。
- 数据来源：仓储费总额取现有仓库总计；吨天取现有批次明细。
- 注意事项：
  - 不对不同费率做简单平均。
  - 总吨天为0时返回0，避免除零。

## 仓储费总额（元）

- 业务含义：现有FIFO计费引擎计算的仓库期间总费用。
- 数学公式：`已出库仓储费＋仍在库仓储费`。
- 数据来源：现有 `EngineResult.warehouse_total` 的
  “系统计算仓储费（元）”。
- 注意事项：分析层不得重新计算费用，必须直接使用核心引擎结果。

## 费用敏感性分析

### 用途

费用敏感性分析用于回答以下管理问题：

- 平均库存量变化时，仓储费可能如何变化；
- 平均存放天数变化时，仓储费可能如何变化；
- 平均仓储费率变化时，仓储费可能如何变化；
- 在设定的模拟范围内，哪个因素对费用的最大影响更大。

### 计算公式

每次只改变一个因素，费用采用线性模拟：

`模拟值 = 基准值 ×（1＋变化比例）`

`模拟仓储费 = 当前仓储费 ×（1＋变化比例）`

`费用变化金额 = 模拟仓储费－当前仓储费`

`费用变化比例 = 费用变化金额÷当前仓储费`

模拟范围：

- 库存量：-10%、-5%、0%、+5%、+10%；
- 存放天数：-10%、-5%、0%、+5%、+10%；
- 费率：-20%、-10%、0%、+10%、+20%。

### 模拟假设

所有结果必须理解为：

> 单因素线性模拟，其他因素保持不变。

库存量情景使用第四阶段的平均库存量，存放时间情景使用全部计费明细的
重量加权平均存放天数，费率情景使用综合平均仓储费率。基准费用直接使用
第四阶段的仓储费总额。

### 为什么不是重新执行FIFO

敏感性分析不调整任何原始出入库流水，也不改变批次日期、出库顺序或费率
配置，因此不存在一组新的真实FIFO队列。它只是把已经计算完成的仓储费按
单一驱动因素的变化比例进行线性缩放。

该模型不得用于替代以下计算：

- 批次级FIFO重建；
- 跨批次出库拆分；
- 新费率规则重新匹配；
- 真实库存变化后的重新计费。

### 敏感性排序

每个因素分别取得最大正向影响金额和最大负向影响金额，再以二者中的最大
绝对值作为影响强度。影响排名按绝对影响金额从大到小采用密集排名；影响
金额相同的因素排名相同。

### 适用场景

- 预算和经营计划；
- 库存压降目标测算；
- 周转效率改善情景；
- 合同费率谈判；
- 管理层快速判断费用驱动方向。

不适用于需要精确预测具体批次、具体日期或特殊计费规则的场景。
