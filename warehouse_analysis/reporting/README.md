# 仓储分析报告说明

## 1. 报告结构

`build_business_report()` 生成固定顺序的十二张工作表：

1. **首页摘要**：管理层查看仓库、期间、库存、库龄、费率、仓储费、异常和数量守恒状态。
2. **仓库经营分析**：第四阶段 `warehouse_summary` 的完整指标。
3. **批次明细**：FIFO拆分后的已出库和仍在库明细。
4. **按物料汇总**：物料层面的数量、周转/库龄及费用汇总。
5. **按品类汇总**：品类层面的数量、周转/库龄及费用汇总。
6. **仓库总计**：仓库层面的引擎总计。
7. **月末库存快照**：平均库存量的月末移动平均计算依据。
8. **费用敏感性分析**：库存量、存放天数和费率的单因素线性模拟。
9. **敏感性影响排名**：按情景范围内的最大绝对费用影响排序。
10. **费率匹配记录**：展示使用的匹配层级、对象、单价、生效日期及人工核对状态。
11. **异常记录**：合并FIFO异常与费率人工核对事项。输入校验错误会在生成报告前阻止运行，不会被转换为结果行。
12. **数量守恒校验**：逐入库批次核对已出库数量与仍在库数量。

旧版 `export_result()` 保留原有结构和“仓储费差异归因分析”工作表。本阶段的
`build_business_report()` 接口保留 `attribution_result` 参数，但固定十二张
业务工作表中暂不新增归因页。

## 2. 数据来源

- FIFO明细、各级汇总、月末快照、异常和数量守恒：`EngineResult`。
- 仓库经营分析和首页经营指标：`warehouse_summary`。
- 敏感性明细和排名：`fee_sensitivity`、`sensitivity_ranking`。
- 费率追溯和人工核对事项：`rate_match_result`。

报告层只读取上述结果，不重新执行FIFO、不重新匹配费率，也不重新计算已有仓储费。

## 3. 格式规则

- 金额：`#,##0.00`
- 数量：`#,##0.000`
- 天数：`#,##0.00`
- 费率：`#,##0.0000`
- 日期：`yyyy-mm-dd`

所有工作表均设置统一表头、自动筛选、自动列宽和冻结窗格。首页对数量守恒异常
和待人工核对数量使用条件格式突出显示。

## 4. 刷新流程

1. 通过输入模块读取标准业务文件或历史兼容三表合一文件。
2. 调用现有引擎生成 `EngineResult`。
3. 调用经营分析与敏感性模块生成对应DataFrame。
4. 准备费率匹配记录和可选归因结果。
5. 调用 `build_business_report(..., output_path)` 生成报告。
6. 重新打开工作簿，核对Sheet顺序、异常数量和数量守恒状态。

## 5. 业务人员使用方法

优先查看“首页摘要”判断库存、费用、异常与守恒状态；再通过“仓库经营分析”
查看经营指标，通过“批次明细”和各级汇总追溯费用，通过“月末库存快照”核对
平均库存，通过“费用敏感性分析”评估管理情景。敏感性结果是单因素线性模拟，
其他因素保持不变，不代表重新执行FIFO后的预测结果。
