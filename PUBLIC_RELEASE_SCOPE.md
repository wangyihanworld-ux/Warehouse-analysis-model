# Public release scope

This copy is prepared for public source publication.

Excluded from the public copy:

- real ERP and opening-inventory files
- business reports and validation workbooks
- SQLite databases, logs, run history, and user settings
- production rate databases and all rate-database backups
- EXE files and release-package backups
- older release directories, temporary files, virtual environments, and generated caches
- migration scripts tied to a specific warehouse or contract
- tests that require real business fixtures

Warehouse names in the remaining example code are replaced with generic example names. The public copy contains no production rate data.
