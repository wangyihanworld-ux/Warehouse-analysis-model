# 规则来源与复核边界

- 公司已确认：FIFO；申请人亲自整理输入表、调整费率、输入计费规则，并随机抽查近100份出入库资料。抽查不是准确率或全面验收。
- 技术设计：库存不足整笔拒绝；同日交易按来源顺序；技术行号定位输入，不是业务唯一标识，不按相同行内容去重。
- 计费简化：按出库日或截止日匹配一个费率，乘整个存放期的数量与天数。日期差为截止日减入库日，同日为零；不按费率生效日分段。此简化不能称为已确认合同规则。
- 仓储费不是采购存货成本，也不是会计期间应计费用；统计开始日不把全龄费用截断。
- 新增：分配明细直接保留入库和出库源行；库存不足异常带字段、状态和核查动作；报告首页提示异常结果不能视为完整执行。
- 输入格式错误仍可能整体阻断，尚未统一为所有字段逐行清单；不宣称全部异常都已有逐行反馈。
- 合成 demo 自动生成旁置 manifest，记录输入文件哈希、期间、计费模式、Python、Git HEAD及实际Python源码哈希。需保留对应文件；不是不可篡改审计系统，也未覆盖全部GUI历史运行。
